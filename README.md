# Codex AutoContinue

A Windows desktop utility for resuming selected local Codex CLI sessions.

`csharp` `windows` `wpf`

[Portfolio](https://dr01d.info/projects)

## Run locally

```text
dotnet build CodexAutoContinue.sln -c Release
```

See [project documentation](README.project.md) for detailed setup, architecture and limitations.
