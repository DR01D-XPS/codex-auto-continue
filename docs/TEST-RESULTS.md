# Результаты проверки Codex AutoContinue

Первичная проверка: 9 октября 2026. Повторная проверка версии 1.0.1: 10 октября 2026. Среда: Windows 11 Pro x64, версия ОС 10.0.26300; SDK .NET 10.0.401; среда выполнения .NET / Windows Desktop 10.0.12. Установленный CLI: `codex-cli 0.162.0-alpha.17.2`, авторизация ChatGPT.

**Результат: 61 из 61 автоматических тестов прошли. Release WPF собран без предупреждений и ошибок. Self-contained EXE опубликован и запущен на этой Windows-машине.**

## Логика и процессы

Тестовый транспорт возвращает реальные формы JSON протокола; тесты не обращаются к модели и не расходуют лимиты аккаунта. Дополнительно используются настоящие процессы для передачи аргументов и Windows Job Object.

| Сценарий | Проверенный результат |
|---|---|
| Одно исчерпанное окно | Ожидание только его сброса, без ненужного ожидания недельного окна |
| Два исчерпанных окна | Выбирается поздний сброс среди блокирующих окон |
| Только недельное окно | Ожидание недельного сброса |
| Нет `resetsAt` | Блокировка продолжается, включается увеличенный интервал |
| Неизвестная доступность | Нет запуска при `ordinaryUsageAllowed: null`, пустом ответе или неидентифицированной исчерпанной квоте |
| Дополнительные кредиты | `ordinaryUsageAllowed: false` и ограничения сервера блокируют запуск; кредиты и сбросы не потребляются |
| Пробуждение | Новое чтение лимитов, независимо от следующей запланированной проверки |
| Перезапуск | Ожидание и точный ID сохраняются; отключённое восстановление и явная остановка имеют приоритет |
| Новая задача до первого запуска | Ожидает без неподтверждённой истории; учтено непостоянство пустой сессии CLI |
| Повторное исчерпание | Новый цикл ожидания в той же сессии |
| Нормальный ответ | «Завершено», без цепочки автоматических «продолжай» |
| 100% во время выполнения | Работающий запуск не прерывается из-за индикатора |
| Одновременный запуск | Второй запуск запрещён контроллером; отдельные владельцы запрещены файловой блокировкой |
| Передача из другого клиента | Требуется явное подтверждение; незавершённая история блокирует запуск |
| Повторный `thread/resume` | Успешная передача подключает сессию один раз; дальнейшие запуски используют её в том же сервере |
| Конфликт внешнего исполнителя | Русское сообщение, пауза, отключение автопродолжения; неподтверждённое владение не сохраняется |
| Повторная передача после освобождения | Явная повторная передача успешна и запускает ровно один turn |
| Потеря ответа `thread/resume` | Собственный `thread/loaded/list` подтверждает загрузку без повторного подключения |
| Старое неподтверждённое владение | При восстановлении версия 1.0.1 требует явную передачу и не запускает работу автоматически |
| Выгрузка сессии | `thread/closed` сбрасывает кеш; перед следующим turn требуется новое подключение |
| Конфликт после перезапуска | Восстановленное ожидание приостанавливается; модельный запрос не отправляется |
| Изменение истории | Автопродолжение приостановлено до повторной передачи |
| Потеря подтверждения | Сохраняется намерение; повтор запрещён; только соответствующее завершённое сообщение может подтвердить результат |
| Чужой новый запуск | Не принимается за подтверждение потерянного запроса |
| Авторизация | Ошибка входа отделена от лимита; API-ключ и другой провайдер отклонены |
| Потеря интернета | Нет модельных «проверочных» запросов; увеличивается интервал чтения |
| Выход локального сервера | Сохраняется причина ожидания; переподключение требует нового чтения лимитов |
| Разрешения / вопросы | Ожидание явного ответа; повторный ответ и повторный запрос не приводят к второму выполнению |
| Неизвестные события | Уведомления не запускают работу; неизвестные запросы отклоняются |
| Пути и аргументы | Кириллица, пробелы, кавычки, `$()` и обратные кавычки передаются буквально, без оболочки |
| Состояние | Атомарная запись, восстановление, карантин повреждённого JSON |
| Журнал | Скрытие известных форматов секретов, ротация и очистка |
| Дочерние процессы | Реальный Windows Job Object завершает родителя и его дочерний процесс |

Полный перечень и итог: [tests.txt](../artifacts/checks/tests.txt).

## Реальный Codex CLI

Через **C# транспорт приложения**, без `turn/start` и без изменения рабочих сессий, проверены:

- запуск нативного `codex.exe app-server --listen stdio://` и handshake;
- `account/read`: управляемый вход ChatGPT;
- `account/rateLimits/read`: декодированы два окна, поле `ordinaryUsageAllowed` присутствует;
- `thread/list`: обнаружены локальные сессии, включая источник `vscode`; количество текущего запуска записано в `integration.txt`;
- `thread/loaded/list`: отдельный свежий сервер возвращает пустой список собственных загруженных сессий;
- `thread/read` с `includeTurns: true`: сервер вернул именно запрошенный ID и историю;
- завершение транспорта: PID дочернего App Server действительно завершился.

Результат: [integration.txt](../artifacts/checks/integration.txt). Python-проба используется только как вспомогательная диагностика, не является зависимостью приложения.

Отдельная проба с временным `CODEX_HOME` подтвердила: `thread/start` принимается без модельного запуска, но `thread/resume` пустой сессии возвращает `no rollout found`, пока первый turn не материализовал историю. Этот случай обработан для собственных новых задач, которые ещё ни разу не отправлялись. Существующие переданные сессии всегда сохраняют свой точный ID. Результат: [isolated-resume.txt](../artifacts/checks/isolated-resume.txt).

Используемые схемы сгенерированы командой установленного CLI (`generate-json-schema`, `generate-ts`) и сохранены в `docs/protocol`, `docs/protocol-ts`. Проверены методы, поля ошибок и разрешений; вымышленных методов или флагов не используется.

## Интерфейс и опубликованный EXE

Опубликованный self-contained `CodexAutoContinue.exe` выполнен с `--smoke-test` в отдельном профиле данных:

- окно WPF на русском, тёмная тема;
- основной и компактный размеры 1300×910 и 1050×710, прокрутка доступна;
- визуализация в 150% с высоким разрешением; фактическое DPI финального запуска Windows — 120 (125%), манифест `PerMonitorV2`;
- реальный `NotifyIcon`, скрытие окна и открытие через пункт меню трея;
- диалог разрешения на команду с кириллицей и кавычками;
- тёмный список сессий;
- реальная запись автозапуска в HKCU, проверка корректного пути, удаление записи; ранее существовавшее значение восстановлено;
- полный выход тестового приложения.

Результат: [ui-smoke.txt](../artifacts/checks/ui-smoke.txt). ## Практические пределы проверки

Реальное исчерпание аккаунта и многочасовой / недельный сброс намеренно не выполнялись. Полный цикл возобновления, разрешения, отключения сети и сбои проверены имитацией; реальная модельная задача в выбранной пользовательской VS Code-сессии не запускалась. Успешный `thread/resume` рабочей VS Code-сессии с последующим выполнением поэтому не является результатом интеграционной проверки.

Нет отдельной машины Windows 10 и проверки физического переключения мониторов с разным DPI. Windows 10 и WSL не выдаются за проверенные окружения: поддержка нативного Windows 10 ограничена условиями поддержки .NET, WSL не реализован. Новые версии экспериментального App Server могут менять протокол; чтение неизвестных данных не подтверждает доступность.
